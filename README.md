# shadow-meme-dashboard

Static front-end for the SHADOW MEME SNIPER **paper-trading** dashboard (GitHub Pages).

- Contains no data and no secrets. All numbers are loaded at runtime from the bot's API
  (`config.json` → `api_base`) and require either Telegram Mini App `initData` (validated
  server-side) or a private access key.
- Paper trading only: virtual money, no wallet, no real transactions.
